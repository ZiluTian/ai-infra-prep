# 全书总览与阅读路线

## 约定

- **难度**:★(需少量前置)~ ★★★★★(专家级)。
- **分层标记**:章节大纲中 `[基础]` = 3-5 年读者必读;`[进阶]` = 5 年+ 或冲源码级/生产级深度者必读。未标注的默认为 `[基础]`。
- **动手**:需 GPU 环境(或可代码走读);**面试钩子**:本章支撑 Ch28 哪类题、Ch29 哪个案例。

## 写作约定(正文阶段执行)

1. **每章开头**:"读完本章你能做什么"清单(3-5 条,可验证)。
2. **公式**:编号 + 统一单位制(GB/TB、μs/ms、TFLOPS、GB/s);每个公式配一个手算例子。
3. **图**:三类——架构图(组件与数据流)、时序图(请求/迭代级 timeline)、Roofline/曲线图;统一编号。
4. **源码块**:标注框架版本 + 文件路径 + 关键行(版本基线见附录 G);代码保持可读性,超长函数贴"骨架 + 关键行"。
5. **案例框**:"生产案例"框(脱敏合成案例,标注假设条件);**踩坑框**:"真实坑"(现象 → 误诊 → 正解)。
6. **每章结尾**:5 道自测题(答案在书末/附录)+ 实验/面试钩子清单。
7. **数据标注**:所有实测数字标注环境(硬件、框架版本、负载)——没有标注的数字视为不可信。
