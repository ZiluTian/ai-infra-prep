# 《大模型推理部署与加速》书籍项目

> 目标:写一本能帮助读者达到「大模型部署与推理加速专家」水平的书——覆盖 vLLM / SGLang / TensorRT-LLM 源码级优化、CUDA 算子、TP/EP/PP/CP 分布式推理、TTFT/TPOT 性能优化闭环与线上稳定性,并以面试题库与系统设计案例收尾。

## 设计原则

1. **从"会用"到"能改"**:每个框架能力都讲到源码级——数据结构在哪、调度决策在哪、kernel 边界在哪,而不是参数手册。
2. **量化优先**:能算的都必须算——KV 显存、通信量、带宽上限、投机解码加速期望、集群容量。
3. **闭环导向**:每个优化都走「假设 → 压测 → 定位 → 落地 → 回归」的完整闭环(Part VI 实验即闭环演练)。
4. **分层可读**:`[基础]` 小节面向 3-5 年经验、需要系统补原理的读者;`[进阶]` 小节面向 5 年+、冲源码级与生产级深度的读者。每章标注难度 ★~★★★★★ 与两条阅读路线(见 `outline/00`)。
5. **面试对齐**:每章标注支撑的题库类别(Ch28)与系统设计案例(Ch29),学完即可直接用于面试。
